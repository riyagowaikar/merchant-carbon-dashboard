# Merchant Dashboard + Carbon Credits

## Problem
Merchants lack transparency in UPI settlements and customers lack visibility into sustainability impact.

## Solution
A blockchain‑powered merchant dashboard that:
- Shows real‑time transactions with immutable records.
- Tracks carbon credits earned/consumed per payment.
- Provides analytics for merchants and customers.

## Tech Stack
- Backend: Python + FastAPI
- Frontend: React
- Database: PostgreSQL / JSON
- Blockchain: Mock ledger with hashes
